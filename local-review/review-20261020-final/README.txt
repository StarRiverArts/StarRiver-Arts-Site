StarRiver Arts — 本機平行網站審查

雙擊 START_REVIEW.cmd，瀏覽器會直接開啟給觀眾看的修訂版網站。
本電腦已備妥 Python；不需要 npm、安裝新套件或連線下載資產。

審查室提供：
  三站總覽：Studio、ProjectT、Museum。
  逐頁探索：完整 101 頁，包含原型及展覽中的設計展示。
  並排比較：同頁原版／修訂版。
  頁面搜尋、網站篩選、只看修訂、手機／平板／桌面寬度及中英文切換。
  獨立開啟：在完整瀏覽器視窗中自由導航。

baseline/ 是原版網站；proposal/ 是修訂版網站。
兩份都附帶 HTML、CSS、JS、影像、字型、互動展示及已公開的 JSON 資料。
此資料夾可獨立於原始碼儲存庫使用。請保留其完整內容。

網站入口：http://127.0.0.1:4190/proposal/
內部比較工具：http://127.0.0.1:4190/
若該埠已由別的本機服務使用，啟動器會選下一個可用埠並顯示網址。
相同副本已啟動時，重複雙擊只會重新開啟既有服務。

停止：按審查室右上方「停止預覽」，或在啟動視窗按 Ctrl+C。
沒有 Windows service、排程或開機自動執行設定。

本機副本不對外發布，所有回應均標記 noindex。
外部社群、VRChat 等連結保留，只有你主動開啟時才會前往外部網站。
原版的已知斷鏈保留作為比較；提案版的必要本地引用均已檢查。
未公開的文章／展覽維持 noindex 及導覽排除；頁面使用一般空白狀態，不展示編輯註解或虛構內容。
兩個舊展場研究工具仍為固定桌面工作區，並保留工具內的中英對照標籤。
